# Материалы для Chrome Web Store

Готовые тексты для вкладок Store listing и Privacy в Developer Dashboard.
Копировать как есть; места, требующие вашего решения, помечены `<...>`.

## Пакет

`build/task-taker-<версия>.zip` — собирается из `manifest.json`, `icons/`, `src/`.
Больше в архиве быть ничего не должно: в корне репозитория лежит
`fct-insert-body.json` с настоящими ФИО и номерами прав водителей, и архивация
папки целиком отправила бы эти данные в Google.

**Description**

```
Task Taker помогает диспетчеру FlowConnect не упускать новые заявки.

Расширение следит за таблицей задач на alpha.flowconnect-group.com и, как только
появляется свободная заявка подходящего типа, нажимает «Start Transaction» и
подтверждает диалог — то же самое, что делает человек, только без задержки на
реакцию.

Возможности:

• Приоритеты типов задач. Список задаёте вы: что выше — берётся раньше, снятая
  галочка — не берётся никогда. Если в один момент появилось несколько заявок,
  расширение сначала сравнит их между собой и возьмёт самую важную.
• Фильтр по порталам ELD88 и FLOW.
• Dry Run — режим проверки: расширение ведёт журнал, но ничего не берёт.
• Панель на странице задач: состояние захвата, счётчик за смену, включение
  одним кликом. Перетаскивается мышью.
• Горячая клавиша для включения и выключения (назначается в настройках Chrome).
• Мягкий звуковой сигнал при взятии заявки, отключаемый.
• Журнал последних событий и счётчики за сутки.
• Предупреждение, если платформа изменила вёрстку и захват перестал работать —
  иначе поломку замечают только к концу смены.

Расширение работает только на alpha.flowconnect-group.com и только под вашей
учётной записью — никаких дополнительных доступов ему не требуется. Данные
никуда не отправляются: настройки и журнал хранятся в вашем браузере.
```

## Privacy

**Single purpose**

```
Расширение автоматизирует один сценарий: взятие свободных рабочих заявок в
диспетчерской панели alpha.flowconnect-group.com сотрудником, у которого уже
есть доступ к этой панели.
```

**Обоснование разрешений**

`storage`
```
Хранит настройки пользователя (приоритеты типов задач, фильтр порталов,
задержки, тумблеры), журнал последних 50 событий и счётчики за текущие сутки.
Всё хранится локально в браузере.
```

`scripting`
```

вкладку платформы, открытую до установки или обновления расширения. Без этого
пользователю пришлось бы перезагружать страницу вручную. Внедрение возможно
только во вкладку alpha.flowconnect-group.com.
```

`https://alpha.flowconnect-group.com/*`
```
Единственный сайт, с которым работает расширение: оно читает таблицу задач и
нажимает кнопки на этой странице. Других доменов в манифесте нет.
```

**Remote code:** No, I am not using remote code — весь код входит в пакет.

**Data usage:** не отмечать ни одну категорию. Расширение не собирает и не

## После публикации

1. Удалить распакованную копию расширения из `chrome://extensions`, иначе рядом
   будут работать два экземпляра и оба начнут хватать заявки.
2. Установить расширение по ссылке магазина.
3. Назначить горячую клавишу на `chrome://extensions/shortcuts` — одиночные
   F-клавиши задаются только вручную (см. раздел 37 в platform-notes.md).

Обновление версии: поднять `version` в манифесте → пересобрать zip → загрузить
в консоли → дождаться проверки. Дальше Chrome разносит новую версию всем
пользователям сам, примерно раз в пять часов.
